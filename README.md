# SCOPE
SOC2 Assessment Framework
🧠 Your Pre-Answer Framework: SCOPE

Before answering any SOC 2 assessment question, run this quickly:

S — Scope

What exactly are we assessing?
Don't assume the whole company, system, or environment.

C — Cause & Risk

What could go wrong, and why does it matter?

O — Observe the Control

What control actually exists?
Don't confuse the policy, tool, implementation, and control.

P — Proof

What evidence proves what actually happened?
And remember: missing evidence ≠ automatic proof that the activity never happened.

E — Evaluate

What can I legitimately conclude?
Is it a design issue, operating issue, evidence gap, or something requiring more investigation?

→ Then act

Only after SCOPE:

Prioritize → Remediate → Document

⚡ Ultra-short version for your brain

Don't assume. Don't conclude. Don't fix yet.

Then:

Scope → Risk → Control → Proof → Conclusion → Action
